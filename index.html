Connect GitHub

Save to Antavatech/tournament-golf-tracker in the rounds folder on the round-data branch. Saved rounds will be public.

In GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens. Create a token for only tournament-golf-tracker, with Contents set to Read and write. Choose an expiration date.

Your token is kept only while this page is open. It is never included in saved round files.
